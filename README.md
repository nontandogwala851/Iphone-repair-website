# Funky Repairs - iPhone Repair Website

This is a simple responsive static website built with HTML, CSS and JavaScript.

## Run in VS Code
1. Extract/open this folder in VS Code.
2. Install the Live Server extension if needed.
3. Right-click `index.html` and choose **Open with Live Server**.

## What was fixed in this version
- Removed the old CSS-drawn/animated phone markup that was overlapping the hero.
- The hero now uses the realistic phone image cleanly and has only a subtle, professional floating animation.
- Rebuilt the six repair-service icons so they visually match the blue icon style of the reference design.
- Added six repair services: Screen, Battery, Camera, Charging Port, Speaker and Other Repairs.
- Removed the Car Charger card completely.
- Kept four accessories: Screen Protector, Fast Charger, Charging Cable and Phone Case.
- Improved responsive behaviour for phones and tablets.
